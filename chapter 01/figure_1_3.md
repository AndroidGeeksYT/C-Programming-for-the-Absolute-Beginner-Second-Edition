# Multi-line Comment Block

```bash
/* C Programming for the Absolute Beginner */
```

# Single Comment Block

```bash
//by Michael Vine
```

# Preprocessor Directive

```bash
#include <stdio.h>
```

# Standard Input/Output Library

```bash
stdio.h
```

> [!TIP]
> stdio.h is a header file.

# Main Function

```bash
int main(void)
```

> [!TIP]
> void is a parameter list that tells the compiler that the function takes no argument

# Begin/End Logical Program Block

```bash
{ }
```

# Program Statement

```bash
printf("\nC you later\n");
```

# Program Statement Terminator

```bash
;
```

> [!TIP]
> ; think of it as a period on a sentence.

# Escape Sequence

```bash
\n
```

> [!TIP]
> \ is an escape sequence and n stands for newline.

# Function

```bash
printf();
```

> [!TIP]
> printf() function is from stdio.h (standard input/output library).
